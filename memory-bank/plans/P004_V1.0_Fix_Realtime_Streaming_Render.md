## Steps:

**1. Adjust `AnalysisWindowContent.tsx` JSX for Real-time Streaming Display**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/analysis/AnalysisWindowContent.tsx`
    *   **Details:**
        *   Modify the component's return statement, specifically the section responsible for rendering the analysis content.
        *   Ensure that `analysisContent` (if it contains actual text and not just a placeholder) is rendered even when `isStreaming` is `true`.
        *   The loading/streaming indicator (e.g., `<Spin /> Streaming analysis...`) should be displayed in a way that doesn't hide the accumulating `analysisContent`. For example, it can be placed below the content.
        *   The logic for displaying `Empty` state or "Re-analyze News" button should only apply when `isStreaming` is `false` AND `analysisContent` is empty or a placeholder.
        
        **Proposed JSX modification in the return statement's content area:**
        ```typescript
        // In frontend/src/components/analysis/AnalysisWindowContent.tsx return statement's content area

        // ... (Title, metadata, header analyze button remain the same) ...

        <div style={{ /* styles for scrollable area */ flexGrow: 1, overflowY: 'auto', minHeight: 0, paddingRight: '8px' }}>
          {/* Always render analysisContent if it has actual content */}
          {analysisContent && analysisContent !== 'No analysis generated or content available.' && (
            <Paragraph style={{ whiteSpace: 'pre-wrap', marginBottom: 0 }}>
              {analysisContent}
            </Paragraph>
          )}

          {/* If streaming, show a loading indicator (e.g., below the content) */}
          {isStreaming && (
            <div style={{ textAlign: 'left', padding: '10px 0 0 0', color: 'var(--text-secondary)' }}>
              <Spin size="small" style={{ marginRight: '8px' }} />
              <em>Streaming analysis...</em>
            </div>
          )}

          {/* If not streaming AND no valid content, then show Empty or Re-analyze button */}
          {!isStreaming && (!analysisContent || analysisContent === 'No analysis generated or content available.') && (
            newsItem && newsItem.analysis ? ( // Original analysis existed, but current attempt (if any) failed or content is empty
              <div style={{ textAlign: 'center', marginTop: '20px' }}>
                <Paragraph type="secondary" style={{marginBottom: '12px'}}>
                  The previous attempt to re-analyze yielded no content, or the original analysis could not be displayed.
                </Paragraph>
                <Button type="primary" onClick={handleForceAnalysis} loading={isStreaming}>
                  Re-analyze News
                </Button>
              </div>
            ) : ( // No original analysis, and current attempt (if any) failed or content is empty
              <Empty 
                description={
                  <>
                    No analysis available for this item. 
                    Click the <ExperimentOutlined style={{ color: 'var(--accent-color)'}} /> icon in the header to generate one.
                    {analysisContent === 'No analysis generated or content available.' && 
                     ' The previous attempt yielded no content.'}
                  </>
                }
                image={Empty.PRESENTED_IMAGE_SIMPLE}
              />
            )
          )}
        </div>
        ```
    *   **Acceptance Criteria:**
        *   When `handleForceAnalysis` is streaming data, the `analysisContent` state updates are reflected in real-time on the UI, with new text chunks appearing as they arrive.
        *   A "Streaming analysis..." indicator is visible during the streaming process.
        *   Once streaming stops, the indicator is removed, and the final content remains.
        *   The display logic for existing analysis, empty states, and error states remains correct.
