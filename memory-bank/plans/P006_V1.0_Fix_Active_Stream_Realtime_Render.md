# Plan P006_V1.0: Fix Active Stream Real-time Rendering in AnalysisWindowContent

**Plan ID:** P006
**Version:** V1.0
**Status:** Active
**Related Issue(s)/Ticket(s):** User Request (May 15, 2025 - Active analysis stream not rendering chunks in real-time on the visible page)
**Implementation Commit(s):** 
    *   SHA: d6b84baeabe75074188a388c261a7730f9a125f6 - feat(P002-P007): Implement frontend stream manager & UI/UX enhancements
**Primary Goal:** Ensure that when `AnalysisWindowContent.tsx` is mounted and its `handleForceAnalysis` function is actively receiving data chunks from the backend stream, these chunks are immediately appended to the UI, providing a visible real-time streaming effect.
**Description:** This plan focuses on verifying and, if necessary, correcting the state update and rendering logic within `AnalysisWindowContent.tsx`. The primary suspect is the existing JSX conditional rendering logic that might prevent the display of `analysisContent` while `isStreaming` is true. The plan involves modifying the JSX to allow `analysisContent` to render and update concurrently with a streaming indicator. Diagnostic logging will be added to trace data flow.

## Pre-computation/Pre-analysis:
*   The JSX structure modified by Plan P004 for `AnalysisWindowContent.tsx` *should* theoretically support real-time updates. The reported issue suggests a bug in that implementation or an unforeseen interaction. The main task is to adjust the JSX conditions for displaying `analysisContent` and the `isStreaming` indicator so they can coexist and `analysisContent` updates show immediately.

## Steps:

**1. Modify JSX in `AnalysisWindowContent.tsx` for Concurrent Display**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/analysis/AnalysisWindowContent.tsx`
    *   **Details:**
        *   The core change is to ensure the `<Paragraph>` displaying `analysisContent` is rendered *unconditionally* as long as `analysisContent` has meaningful text, even if `isStreaming` is true. The streaming indicator will be shown separately.
        *   The old logic from P004 was:
            ```jsx
            {analysisContent && analysisContent !== 'No analysis generated or content available.' && (
              <Paragraph style={{ whiteSpace: 'pre-wrap', marginBottom: 0 }}>
                {analysisContent}
              </Paragraph>
            )}
            {isStreaming && ( /* ... spinner ... */ )}
            {/* ... other states for !isStreaming ... */}
            ```
        *   The proposed new structure inside the scrollable `div`:
            ```typescript
            // In frontend/src/components/analysis/AnalysisWindowContent.tsx return statement's content area

            {/* Render analysisContent if it's not empty or the placeholder message */}
            {analysisContent && analysisContent !== 'No analysis generated or content available.' && (
              <Paragraph style={{ whiteSpace: 'pre-wrap', marginBottom: 0 }}>
                {analysisContent}
              </Paragraph>
            )}

            {/* Show streaming indicator if isStreaming is true */}
            {isStreaming && (
              <div style={{ textAlign: 'left', padding: '10px 0 0 0', color: 'var(--text-secondary)' }}>
                <Spin size="small" style={{ marginRight: '8px' }} />
                <em>Streaming analysis...</em>
              </div>
            )}

            {/* Show Empty state or Re-analyze button only when NOT streaming AND no valid content */}
            {!isStreaming && (!analysisContent || analysisContent === 'No analysis generated or content available.') && (
              newsItem && newsItem.analysis ? ( 
                // ... Re-analyze button logic ...
                <div style={{ textAlign: 'center', marginTop: '20px' }}>
                  <Paragraph type="secondary" style={{marginBottom: '12px'}}>
                    The previous attempt to re-analyze yielded no content, or the original analysis could not be displayed.
                  </Paragraph>
                  <Button type="primary" onClick={handleForceAnalysis} loading={isStreaming}>
                    Re-analyze News
                  </Button>
                </div>
              ) : ( 
                // ... Empty state logic ...
                <Empty 
                  description={
                    <>
                      No analysis available for this item. 
                      Click the <ExperimentOutlined style={{ color: 'var(--accent-color)'}} /> icon in the header to generate one.
                      {analysisContent === 'No analysis generated or content available.' && 
                       ' The previous attempt yielded no content.'}
                    </>
                  }
                  image={Empty.PRESENTED_IMAGE_SIMPLE}
                />
              )
            )}
            ```
    *   **Acceptance Criteria:**
        *   When `handleForceAnalysis` is actively receiving stream chunks, the `analysisContent` displayed on the page updates in real-time.
        *   The "Streaming analysis..." indicator is visible simultaneously during the streaming process.
