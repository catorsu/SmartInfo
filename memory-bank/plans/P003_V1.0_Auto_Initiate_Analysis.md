# Plan P003_V1.0: Auto-Initiate Analysis on Navigation/Open

**Plan ID:** P003
**Version:** V1.0
**Status:** Active
**Related Issue(s)/Ticket(s):** User Request (May 15, 2025 - Analysis not auto-streaming on click from news list)
**Implementation Commit(s):** 
    *   SHA: d6b84baeabe75074188a388c261a7730f9a125f6 - feat(P002-P007): Implement frontend stream manager & UI/UX enhancements
**Primary Goal:** When a user clicks an "Analyze" button on the news list/card for an item without existing analysis, the analysis page should open and automatically start streaming the analysis in real-time.
**Description:** This involves modifying the "Analyze" button's navigation on the news list page to include a query parameter (`?initiate=true`). The target analysis page (`/analyze/[id].tsx`) will read this parameter and pass a prop to the `AnalysisWindowContent.tsx` component. This component will then use the prop to automatically call its `handleForceAnalysis()` method if the conditions are met (no existing analysis, not already streaming from a session resume, and explicit initiation requested).
**Branch:** `[main/feature-branch-name]`

**File(s) to be Modified (or Created):**
*   `frontend/src/pages/index.tsx` (for the "Analyze" button on news cards)
*   `frontend/src/pages/analyze/[id].tsx` (to handle the query parameter and pass props)
*   `frontend/src/components/analysis/AnalysisWindowContent.tsx` (to accept new prop and auto-initiate analysis)

**2. Update Analysis Page (`analyze/[id].tsx`) to Handle `initiate` Query Parameter**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/pages/analyze/[id].tsx`
    *   **Details:**
        *   Import `useEffect` and `useState` from React.
        *   Read the `initiate` query parameter from `router.query`.
        *   Use `useEffect` to set a state variable `shouldStartAnalysis` based on `initiate === 'true'`, ensuring `router.isReady`.
        *   Pass this state variable as a new prop `startAnalysisImmediately` to the `<AnalysisWindowContent />` component.
        ```typescript
        // In frontend/src/pages/analyze/[id].tsx
        import React, { useEffect, useState } from 'react'; // ADDED useEffect, useState
        import { useRouter } from 'next/router';
        import AnalysisWindowContent from '@/components/analysis/AnalysisWindowContent';
        import { Typography, Alert } from 'antd';
        import withAuth from '@/components/auth/withAuth';

        const { Title } = Typography;

        const AnalyzePage: React.FC = () => {
          const router = useRouter();
          const { id, initiate } = router.query; // Destructure initiate

          const newsItemId = typeof id === 'string' ? parseInt(id, 10) : undefined;
          const [shouldStartAnalysis, setShouldStartAnalysis] = useState(false);

          useEffect(() => {
            if (router.isReady) { // Ensure query params are available
              setShouldStartAnalysis(initiate === 'true');
            }
          }, [router.isReady, initiate]); // Depend on router.isReady and initiate


          if (router.isReady && newsItemId === undefined) {
            return (
              <div style={{ padding: '20px' }}>
                <Alert
                  message="Error"
                  description="Invalid news item ID provided."
                  type="error"
                  showIcon
                />
              </div>
            );
          }

          return (
            <div style={{ padding: '20px' }}>
              {newsItemId !== undefined ? (
                <AnalysisWindowContent
                  newsItemId={newsItemId}
                  startAnalysisImmediately={shouldStartAnalysis} // Pass the new prop
                />
              ) : (
                <div style={{ textAlign: 'center', padding: '50px 0' }}>
                   <Title level={4}>Loading...</Title>
                </div>
              )}
            </div>
          );
        };

        export default withAuth(AnalyzePage);
        ```
    *   **Acceptance Criteria:** `AnalysisWindowContent` component receives the `startAnalysisImmediately` prop correctly based on the URL query parameter.

**3. Modify `AnalysisWindowContent.tsx` to Auto-Initiate Analysis**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/analysis/AnalysisWindowContent.tsx`
    *   **Details:**
        *   Add `startAnalysisImmediately?: boolean;` to the `AnalysisWindowContentProps` interface.
        *   Update the main `useEffect` hook (`fetchNewsAndPotentiallyResumeAnalysis` renamed to `fetchNewsAndHandleAnalysisState` for clarity) to:
            *   If `startAnalysisImmediately` prop is `true`, no existing `item.analysis` is found, and no session storage flag indicates an already ongoing attempt by this session, then `await handleForceAnalysis()` is called.
            *   The logic ensures this explicit initiation trigger works alongside the session storage resume logic from P002.
        ```typescript
        // In frontend/src/components/analysis/AnalysisWindowContent.tsx

        // Modify AnalysisWindowContentProps
        interface AnalysisWindowContentProps {
          newsItemId: number;
          startAnalysisImmediately?: boolean; // New prop
        }

        // In AnalysisWindowContent component, update the main useEffect
        useEffect(() => {
          // Renamed for clarity to fetchNewsAndHandleAnalysisState
          const fetchNewsAndHandleAnalysisState = async () => {
            setIsLoading(true);
            setError(null);
            setAnalysisContent('');
            setNewsItem(null); // Reset news item explicitly

            try {
              const item = await newsService.getNewsById(newsItemId);

              if (item === null) { 
                setNewsItem(null); 
                setError({ type: 'notFound', message: `News item with ID ${newsItemId} not found or not owned by user.`, status: 404 });
                setIsLoading(false);
                setIsStreaming(false);
                return;
              }
              setNewsItem(item); // Set news item first

              const analysisFlagKey = getAnalysisInProgressFlagKey(newsItemId);

              if (item.analysis) {
                setAnalysisContent(item.analysis);
                sessionStorage.removeItem(analysisFlagKey); // Clear flag if analysis is now present
                setIsLoading(false);
                setIsStreaming(false);
              } else { // No existing analysis on the backend
                const isAnalysisInProgressSession = sessionStorage.getItem(analysisFlagKey) === 'true';

                if (startAnalysisImmediately && !isAnalysisInProgressSession) {
                  // Explicitly told to start via prop, and not already flagged as in-progress by this session
                  console.log(`Analysis for item ${newsItemId} explicitly initiated on load via prop.`);
                  await handleForceAnalysis(); // This will set its own session flag
                } else if (isAnalysisInProgressSession) {
                  // Was previously started by this session (e.g., navigation away and back), try to resume UI state
                  console.log(`Analysis for item ${newsItemId} was marked as in progress by this session. Re-initiating stream for UI continuity.`);
                  await handleForceAnalysis(); // This will also re-set the session flag (which is fine)
                } else {
                  // No existing analysis, not told to start immediately by prop, and no session flag
                  // This means the component loaded normally, and the user needs to click the internal "Analyze" button.
                  setAnalysisContent(''); // Ensure content is clear
                  setIsLoading(false);    // Done with initial item load
                  setIsStreaming(false);
                }
              }
            } catch (fetchError: any) {
              console.error("Failed to fetch news item or handle analysis state:", fetchError);
              const errorDetails = extractErrorMessage(fetchError);
              setError(errorDetails);
              setIsLoading(false);
              setIsStreaming(false);
              setNewsItem(null); // Clear news item on error too
            }
          };

          if (newsItemId) {
            fetchNewsAndHandleAnalysisState();
          }
        // Add startAnalysisImmediately to the dependency array.
        }, [newsItemId, startAnalysisImmediately]);
        ```
    *   **Acceptance Criteria:**
        *   When `startAnalysisImmediately` is true, and no backend analysis exists, and no session flag indicates a current attempt, `handleForceAnalysis` is automatically invoked.
        *   The component correctly handles cases where analysis already exists or was previously started in the session (P002 logic).
