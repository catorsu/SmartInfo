# Plan P012_V1.0: Refine Chat UI: Message Copy Button and Input Bar Styling

**Plan ID:** P012

**Status:** Superseded

**Implementation Commit(s):**

**Primary Goal:** Improve the user experience of the chat interface by adjusting the "Copy" button behavior on messages and refining the visual styling of the text input bar.

**Description:** 
This plan addresses two main UI enhancements for the chat page.
First, the "Copy" button for individual chat messages will be repositioned to the bottom-left corner of the message bubble and will only become visible when the user hovers over that specific message. This provides a cleaner look and more intuitive interaction.
Second, the text input bar will be modified to remove the blue border outline that appears on hover and to remove the top border line that currently separates it from the message area. This will create a more seamless and modern appearance for the input field.

**File(s) to be Modified (or Created):**
*   `frontend/src/pages/chat/[id].tsx`
*   `frontend/src/styles/ChatInputBar.module.css`

            *   Style the copy button (or its wrapper) with `position: 'absolute'`, `bottom: '8px'`, `left: '8px'` (adjust pixels as needed for good visual).

**3. Eliminate Hover Border/Outline on Chat Text Input**

        *   Ensure these are fully overridden. Add or confirm the following styles for the `.chatInputTextArea` class and its pseudo-classes:
            ```css
            .chatInputTextArea {
                /* ... existing styles ... */
                border: none !important; /* Already present, confirm effectiveness */
                box-shadow: none !important; /* Already present, confirm effectiveness */
                outline: none !important; /* Add if outline is the issue */
            }

            .chatInputTextArea:hover,
            .chatInputTextArea:focus,
            .chatInputTextArea:focus-within {
                border-color: transparent !important; /* Or specific desired non-hover border color if any */
            ```

            *   The goal is to ensure no border or outline color changes or appears on hover or focus.
    *   **Acceptance Criteria:**

        *   When the text input field is focused, no blue (or any other color) border or outline appears.
