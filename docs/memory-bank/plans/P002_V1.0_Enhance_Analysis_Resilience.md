# Plan P002_V1.0: Enhance Analysis Page Resilience to Navigation

**Plan ID:** P002
**Version:** V1.0
**Status:** Active
**Related Issue(s)/Ticket(s):** User Request (May 15, 2025)
**Implementation Commit(s):** 
    *   SHA: d6b84baeabe75074188a388c261a7730f9a125f6 - feat(P002-P007): Implement frontend stream manager & UI/UX enhancements
**Primary Goal:** Ensure that an ongoing news analysis process is not visually "lost" if the user navigates away and returns to the analysis page, and that completed analysis is displayed correctly upon return.
**Description:** Modify `AnalysisWindowContent.tsx` to use `sessionStorage` to flag when an analysis has been initiated for a news item by the current browser session. If the user returns to the page and the analysis hasn't yet been saved to the backend, the component will attempt to re-initiate the streaming process to reflect the ongoing analysis. If the analysis completed while the user was away, it will be displayed directly. This approach ensures the backend analysis (triggered by `force=true`) continues and the frontend provides a more consistent UX.

**2. Modify `handleForceAnalysis` to Manage Session Storage Flag**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/analysis/AnalysisWindowContent.tsx`
    *   **Details:**
        *   Ensure `handleForceAnalysis` is an `async` function.
        *   At the beginning of `handleForceAnalysis`, set the session storage flag to 'true' for the current `newsItemId`.
        *   In the `finally` block of `handleForceAnalysis` (which executes after the stream attempt, regardless of success or failure), remove the session storage flag.
        ```typescript
        // Inside AnalysisWindowContent component

        const handleForceAnalysis = async () => {
          if (!newsItemId) return;

          const analysisFlagKey = getAnalysisInProgressFlagKey(newsItemId);
          sessionStorage.setItem(analysisFlagKey, 'true'); // Set flag

          setError(null);
          setAnalysisContent('');
          setIsStreaming(true);
          setIsLoading(true); // For initial stream setup / item loading aspect

          try {
            const response = await newsService.streamAnalysis(newsItemId, true); // force=true
            if (!response.body) throw new Error("Streaming response body is empty.");

            const reader = response.body.getReader();
            const decoder = new TextDecoder();
            let firstChunkReceived = false;
            let done = false; // to check if stream ended before first chunk

            while (true) {
              const { value, done: streamDone } = await reader.read();
              done = streamDone; // update done status
              if (done) break;

              if (!firstChunkReceived) {
                setIsLoading(false); // Stop general loading once stream starts
                firstChunkReceived = true;
              }

              const decodedChunk = decoder.decode(value, { stream: true });
              setAnalysisContent(prev => prev + decodedChunk);
            }

            const finalChunk = decoder.decode();
            if (finalChunk) {
              setAnalysisContent(prev => prev + finalChunk);
            }

            if (!firstChunkReceived) { // Stream ended before any content
                setIsLoading(false);
                setAnalysisContent('No analysis generated or content available.');
            }
          } catch (streamError: any) {
            console.error("Forced analysis streaming failed:", streamError);
            const errorDetails = extractErrorMessage(streamError);
            setError(errorDetails);
            setIsLoading(false); // Ensure loading is false on error
          } finally {
            setIsStreaming(false);
            // setIsLoading(false); // Already handled when first chunk arrives or on error
            sessionStorage.removeItem(analysisFlagKey); // Clear flag
          }
        };
        ```
    *   **Acceptance Criteria:**
        *   Session storage flag is set when `handleForceAnalysis` starts.
        *   Session storage flag is removed when `handleForceAnalysis` stream ends or errors out.

**3. Update Initial `useEffect` to Check Session Storage Flag**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/analysis/AnalysisWindowContent.tsx`
    *   **Details:**
        *   Make the `useEffect` callback `async`.
        *   After fetching the `newsItem`:
            *   If `item.analysis` already exists, display it and ensure any session flag for this item is cleared.
            *   If `item.analysis` does *not* exist, check `sessionStorage` for the "analysis in progress" flag for this `newsItemId`.
            *   If the flag is 'true', it means an analysis was likely started by this session and interrupted by navigation. Automatically call `await handleForceAnalysis()` to re-initiate the stream and UI state.
            *   If no flag, the UI will show the "Analyze" button (P001 behavior), and `isLoading` should be set to `false`.
        ```typescript
        // Inside AnalysisWindowContent component, within the main useEffect hook

        useEffect(() => {
          const fetchNewsAndPotentiallyResumeAnalysis = async () => {
            setIsLoading(true);
            setError(null);
            setAnalysisContent('');
            setNewsItem(null); // Reset news item explicitly

            try {
              const item = await newsService.getNewsById(newsItemId);

              if (item === null) {
                setNewsItem(null);
                setError({ type: 'notFound', message: `News item with ID ${newsItemId} not found or not owned by user.`, status: 404 });
                setIsLoading(false);
                setIsStreaming(false); // Ensure streaming is false
                return;
              }
              setNewsItem(item); // Set news item first

              const analysisFlagKey = getAnalysisInProgressFlagKey(newsItemId);

              if (item.analysis) {
                setAnalysisContent(item.analysis);
                sessionStorage.removeItem(analysisFlagKey); // Clear flag if analysis is now present
                setIsLoading(false);
                setIsStreaming(false);
              } else {
                // No existing analysis, check session flag
                if (sessionStorage.getItem(analysisFlagKey) === 'true') {
                  console.log(`Analysis for item ${newsItemId} was marked as in progress by this session. Re-initiating stream.`);
                  // handleForceAnalysis will set isLoading, isStreaming, and manage its own flag.
                  await handleForceAnalysis();
                  // isLoading and isStreaming are managed by handleForceAnalysis
                } else {
                  // No analysis and no flag, normal state, show analyze button
                  setAnalysisContent(''); // Ensure content is clear
                  setIsLoading(false);    // Done with initial item load
                  setIsStreaming(false);
                }
              }
            } catch (fetchError: any) {
              console.error("Failed to fetch news item or resume analysis:", fetchError);
              const errorDetails = extractErrorMessage(fetchError);
              setError(errorDetails);
              setIsLoading(false);
              setIsStreaming(false);
              setNewsItem(null); // Clear news item on error too
            }
          };

          if (newsItemId) {
            fetchNewsAndPotentiallyResumeAnalysis();
          }
        }, [newsItemId]);
        ```
    *   **Acceptance Criteria:**
        *   If analysis exists on the backend, it's displayed.
        *   If no analysis exists but a session flag indicates it was started, `handleForceAnalysis` is called to "resume" the UI streaming state.
        *   If no analysis and no flag, the default state (e.g., "Analyze" button visible) is shown.
