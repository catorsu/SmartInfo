# Plan P009_V1.0: Refactor Chat Page UI Layout and Input Bar

**Plan ID:** P009
**Version:** V1.0
**Status:** Active
**Related Issue(s)/Ticket(s):** N/A
**Implementation Commit(s):** 
    *   
**Primary Goal:** To update the chat page UI to more closely resemble modern chat interfaces like Gemini and Tencent Yuanbao, improving visual appeal and usability.
**Description:** This plan involves modifying the main chat content area's dimensions and centering, and redesigning the chat input bar to have action buttons (send, add file) positioned inside the text input field.

**File(s) to be Modified (or Created):**
*   `frontend/src/pages/chat/[id].tsx`
*   `frontend/src/components/layout/MainLayout.tsx`
*   `frontend/src/components/Chat/ChatInputBar.tsx`
*   `frontend/src/styles/ChatInputBar.module.css`

---

## Pre-computation/Pre-analysis (Optional)
*   **Notes:** The user provided screenshots illustrate the target layout:
    *   Gemini UI: Centered, narrower chat content area.
    *   Tencent Yuanbao UI: Input bar with send and add file buttons inside the text area.

## Steps:

**1. Modify Main Chat Content Area Styles (`chat/[id].tsx` and `MainLayout.tsx`)**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/pages/chat/[id].tsx`, `frontend/src/components/layout/MainLayout.tsx`
    *   **Details:**
        *   In `frontend/src/pages/chat/[id].tsx`:
            *   Target the main `div` wrapping the message list and input bar.
            *   Apply styles (inline or via a new class in `globals.css` or a specific module.css) to achieve:
                *   `maxWidth: '750px'` (adjustable between 700-800px as per preference)
                *   `margin: '0 auto'` (for horizontal centering)
                *   `maxHeight: '85vh'` (or similar, to constrain height)
                *   `display: 'flex'`
                *   `flexDirection: 'column'`
                *   `height: '100%'` (if parent in MainLayout handles viewport height)
        *   In `frontend/src/components/layout/MainLayout.tsx`:
            *   Adjust the `Content` component's wrapper `div` (likely `<main>`).
            *   Apply styles to ensure it fills the available vertical space below the header and can center its content:
                *   `display: 'flex'`
                *   `flexDirection: 'column'`
                *   `justifyContent: 'center'` (for vertical centering of the chat page content)
                *   `alignItems: 'center'` (works with `margin: '0 auto'` on child for horizontal)
                *   `flexGrow: 1` (to take available space)
                *   `overflow: 'hidden'` (to prevent double scrollbars if `maxHeight` is used on child)
                *   `paddingTop` and `paddingBottom` as needed for visual balance if vertical centering isn't perfect due to other elements.
    *   **Acceptance Criteria:**
        *   The chat content area (message list + input bar) is horizontally centered on the page.
        *   The chat content area has a maximum width around 750px.
        *   The entire chat content area (as a block) is vertically centered within the viewport.
        *   The chat content area has a maximum height (e.g., 85vh), and the internal message list remains scrollable.

**2. Redesign Chat Input Bar - TSX Structure (`ChatInputBar.tsx`)**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/components/Chat/ChatInputBar.tsx`
    *   **Details:**
        *   Import `PaperClipOutlined` from `@ant-design/icons`.
        *   Modify the main `div` of `ChatInputBar.tsx` (e.g., with class `styles.chatInputBarContainer` or similar):
            *   Ensure it has `position: 'relative'` to act as the positioning context for the buttons.
        *   The `TextArea` component:
            *   Will need `paddingRight` (e.g., `70px` or `80px`) applied via its `style` prop or a CSS class to prevent text from rendering underneath the internal buttons.
        *   Create a new `div` inside the main container to hold the buttons:
            *   This `div` will be absolutely positioned at the bottom-right of the `TextArea`.
            *   Style it with `display: 'flex'`, `alignItems: 'center'`.
        *   Place the new `PaperClipOutlined` icon button and the existing `SendOutlined` icon button inside this new `div`.
            *   `PaperClipOutlined` should come before `SendOutlined`.
    *   **Acceptance Criteria:**
        *   `PaperClipOutlined` icon is imported and available.
        *   The JSX structure is updated to group the `TextArea` and a new container for the internal buttons.
        *   The buttons are placed within this new container.

**3. Style Chat Input Bar - CSS Positioning (`ChatInputBar.module.css`)**
    *   **Status:** `Completed`
    *   **File(s) Affected:** `frontend/src/styles/ChatInputBar.module.css`
    *   **Details:**
        *   Update `chatInputBar` (or the main container class) to have `position: 'relative'`.
        *   Update `chatTextArea` (or the `TextArea`'s class/style):
            *   Add `paddingRight: '80px'` (adjust based on button sizes and spacing).
            *   Ensure `width: '100%'` and `boxSizing: 'border-box'`.
        *   Create a new CSS class for the buttons' container (e.g., `inputButtonsContainer`):
            *   `position: 'absolute'`
            *   `bottom: '8px'` (adjust for vertical alignment within the textarea)
            *   `right: '8px'` (adjust for horizontal alignment)
            *   `display: 'flex'`
            *   `alignItems: 'center'`
            *   `gap: '8px'` (for spacing between buttons)
        *   Style the individual buttons if needed (e.g., `cursor: 'pointer'`, icon size, color).
            *   The existing `sendButton` class might need adjustments if it has external margins.
    *   **Acceptance Criteria:**
        *   The send button is positioned inside the text input area, at its bottom-right corner.
        *   The new "add file" button is positioned inside the text input area, at the bottom, to the left of the send button.
        *   The text input area remains fully functional, and typed text does not overlap with the buttons.
        *   The visual layout of the input bar resembles the Tencent Yuanbao UI screenshot.
